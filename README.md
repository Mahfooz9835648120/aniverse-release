## ✨ Features

- 🎌 **Multi-audio** — Hindi, Tamil, Malayalam, English, Japanese per episode
- ⏭️ **Auto skip** intro & outro
- 📺 **1150+ episodes** of One Piece, Naruto, Dragon Ball Z and more
- 🔍 **AniList & TMDB** integration — episode art, arc names, filler markers
- 🌐 **Server 1 & 2** with automatic fallback
- 🎨 Dark UI with arc-based episode navigation
